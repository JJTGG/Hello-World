
# Hello World

**From your first repository to your first real project.**

Hello World is an independent, beginner-friendly learning resource for people getting started with Git, GitHub and software development.

It combines clear written guides with practical exercises and a small website built using HTML, CSS and JavaScript. The goal is to help you understand the tools and workflows developers use, then practise them in a real repository.

## Who Is This For?

Hello World supports two learning paths:

- **Complete beginners:** Start with the fundamentals, learn GitHub through its web interface and build confidence one step at a time.
- **Developers new to Git and GitHub:** Focus on version control, repositories, collaboration and practical developer workflows, then apply them to your own projects.

You do not need prior Git experience to get started.

## What You'll Learn

- What Git is and how version control works.
- How GitHub repositories, files and folders are organised.
- How to make and understand commits.
- How branches, merging and pull requests work.
- How to use issues and collaborate on projects.
- How to write useful commit messages with Conventional Commits.
- How to use Git from the command line.
- How to build and publish a simple website.

## Choose a Learning Path

### Path A — Start from Zero

1. Understand the basics of software development and version control.
2. Explore GitHub using its web interface.
3. Create a repository and work with files.
4. Learn commits, branches and pull requests.
5. Build and publish the starter website.
6. Progress to Git on the command line.

### Path B — Learn the Developer Workflow

1. Review the Git and GitHub concepts you need.
2. Practise repository management and commits.
3. Work with branches, merging and pull requests.
4. Learn collaboration and Conventional Commits.
5. Apply the workflow to an existing project.
6. Progress to Git command-line tools.

Both paths use the same documentation and exercises. You can skip material you already understand.

## The Practical Website

The repository includes a small static website made with standard web technologies:

| File | Purpose |
|---|---|
| `index.html` | Page structure and content |
| `style.css` | Appearance, layout and responsive styling |
| `script.js` | Browser interaction |

There is no framework or package installation required to explore the website.

## Get Started

### Option 1 — Use This Template

1. Open this repository on GitHub.
2. Select **Use this template**, then **Create a new repository**.
3. Choose a name and create your copy.
4. Open the new repository and start experimenting with its files.

### Option 2 — Follow the Learning Materials

- Read the [documentation guide](docs/README.md).
- Work through the [practical exercises](exercises/README.md).
- Use the website files to practise editing, committing and publishing a project.

## How We Teach

The learning approach is progressive:

1. Understand the concept.
2. See a practical example.
3. Try it yourself.
4. Check the result.
5. Move on when you're ready.

The initial lessons use GitHub's web interface. Git command-line workflows are introduced later, once the underlying concepts are familiar.
