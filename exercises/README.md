
# Practical Exercises

Welcome to the Hello World practical exercises.

These exercises help you apply what you learn instead of simply reading documentation.

## Exercise Roadmap

| Exercise | Topic |
|---|---|
| 01 | Create Your First Repository |
| 02 | Make Your First Commit |
| 03 | Edit Project Files |
| 04 | Create a Branch |
| 05 | Open a Pull Request |
| 06 | Resolve a Merge Conflict |
| 07 | Publish Your Website |

Exercises will be added progressively. Only attempt an exercise when its instruction file is available.

## How Exercises Work

Each exercise should contain:

- **Objective:** What you are expected to accomplish.
- **Prerequisites:** What you should understand beforehand.
- **Instructions:** Steps to complete the task.
- **Expected Outcome:** What successful completion looks like.
- **Verification:** How to check your work.

## What You Need

- A GitHub account.
- A modern web browser.
- This repository or a copy created from its template.

The initial exercises use GitHub's web interface. Git CLI exercises will be introduced progressively.

## Before Moving On

Don't just copy instructions.

Understand what each action does, why you're performing it and how to verify the result.

Learn at your own pace.
