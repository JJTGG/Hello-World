
# Contributing to Hello World

Thank you for considering a contribution.

Hello World aims to make Git, GitHub and software development easier to understand.

Contributions should improve accuracy, clarity or the practical learning experience without introducing unnecessary complexity.

## Ways to Contribute

You can help by:

- Correcting technical inaccuracies.
- Improving beginner-friendly explanations.
- Fixing spelling, grammar or broken links.
- Adding practical examples.
- Suggesting useful exercises.
- Improving the starter website.
- Reporting unclear or outdated instructions.

## Before You Start

For substantial changes, open an issue first to discuss the proposed improvement.

Small corrections, such as fixing a typo or broken link, can be submitted directly.

Keep each pull request focused on one related change.

## Contribution Guidelines

1. Use clear, direct language.
2. Don't assume readers already understand the topic.
3. Verify technical instructions and code examples.
4. Keep examples practical and reproducible.
5. Avoid unnecessary dependencies.
6. Preserve the existing project structure unless a change is justified.
7. Never include passwords, access tokens, API keys or private information.
8. Respect copyright and licensing requirements.

## Suggested Workflow

1. Fork the repository.
2. Create a branch for your changes.
3. Make and verify your changes.
4. Commit using Conventional Commits.
5. Push your branch to your fork.
6. Open a pull request describing the changes.

You may use GitHub's web interface or Git command-line tools.

## Commit Messages

Use this format:

`type(scope): description`

Examples:

```text
docs(git): explain commit history
feat(website): add homepage navigation
fix(website): correct mobile layout
style(website): improve button appearance
refactor(website): simplify event handling
```

Choose a type that accurately describes the change.

## Pull Requests

A pull request should:

- Have a clear title.
- Explain what changed and why.
- Reference a related issue when applicable.
- Contain only relevant changes.
- Include verification details for code changes.

## Reporting Problems

Use GitHub Issues to report documentation errors, broken examples, unclear instructions or other project problems.

Search existing issues before opening a duplicate.

## Licensing

Do not submit third-party material without the necessary permissions and attribution.

## Final Note

Contributions should make learning easier, more accurate or more useful.

Thank you for helping improve Hello World.
