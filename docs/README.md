
# Learning Documentation

This directory contains guides for learning Git, GitHub and the development workflows used to manage software projects.

The materials are designed for both complete beginners and developers who already know some programming.

## Learning Roadmap

### 01. Foundations
- Introduction to Software Development
- Understanding Git and Version Control
- Understanding GitHub

### 02. GitHub Essentials
- Repositories
- Files and Folders
- README Files
- Repository Settings

### 03. Git Fundamentals
- Understanding Commits
- Working with Branches
- Merging Changes
- Understanding Commit History

### 04. Collaboration
- Forks and Cloning
- Pull Requests
- Issues and Discussions
- Reviewing Contributions
- Resolving Merge Conflicts

### 05. Developer Workflows
- Conventional Commits
- Git Command Line
- Basic Git Workflows
- Publishing with GitHub Pages

## Learning Approaches

### Complete Beginners

Start with the foundations and follow the roadmap sequentially.

The initial lessons use GitHub's web interface before introducing command-line operations.

### Existing Beginner Developers

You can skip introductory programming concepts and focus on Git, GitHub and collaborative development.

## How to Use These Guides

Each guide should include:

- Learning objectives.
- Concept explanations.
- Step-by-step instructions.
- Practical examples.
- Common mistakes.
- Exercises.
- Expected outcomes.

## Availability

This roadmap describes the intended learning sequence. Not every guide is available yet.

Check this directory for currently published lessons.

Learn progressively, practise independently and advance at your own pace.
